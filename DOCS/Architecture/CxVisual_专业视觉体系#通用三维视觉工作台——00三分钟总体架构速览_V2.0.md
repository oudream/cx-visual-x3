## 1. 我们究竟建设什么？

一个面向工业CT/ECT、三维计量、CAD比较、逆向、缺陷检测和自动化的**完整专业三维工作台**。既支持独立软件、Studio嵌入和WPF控件，也支持不依赖界面的专业算法/API。TestCenter只负责真实功能验收。

**用户工作流：导入→空间标定→四视图/ROI观察→表面确定→几何拟合/配准→测量/GD&T/CAD差异→缺陷/壁厚→报告与自动化。**

不是只有四视图的Viewer，也不为26个能力创建26个工程或第二套工程/Runtime/数据体系。

## 4. 六个必须坚持的架构决定

| 设计 | 数据/状态真源 | 绝不做什么 |
|---|---|---|
| 对象和场景 | FVO/CT3D专业数据；MVI Scene投影；MEM唯一工程身份 | Scene成为第二份持久化工程树 |
| 坐标与计量 | FVO原值和Spacing；Geometry/Numerics空间数学；CT3D计量 | 以R8预览、GPU或屏幕像素直接计量 |
| 算法与结果 | CT3D专业算法、Inspection判定、现有运行机制 | 再造一个万能Process/GraphExecutor |
| 交互和动画 | MVI Camera、三刀、选择、ROI；MPW呈现 | WPF和GL各维护长期相机真源 |
| 资源和性能 | FVO原值/Lease；MPW GPU Context/Texture；平台预算与诊断 | 无界复制、GPU失败冒充成功 |
| 专业能力独立 | CT3D可Headless运行，专业结果带版本与质量 | 将Surface/CAD/GD&T算法写入WPF控件 |

## 5. 四个真实工业用例

| 任务 | 工程师操作 | 必须给出的专业证据 |
|---|---|---|
| CT计量 | CT→Surface→Fit→Measurement→GD&T | 单位、基准、拟合残差、工业真值误差 |
| CT-CAD | CT+真实CAD→配准→正负偏差→报告 | 坐标链、CAD拓扑、RMS、超差区域 |
| 缺陷/材料 | CT→Mask→气孔/裂纹/壁厚→判定 | 缺陷体积、分类、最薄点、漏检/误检 |
| 多对象 | Volume/Mesh/CAD/ROI叠加→动画→保存重开 | 源Ref/版本不丢、视角一致、结果可重放 |

以上是完整目标态，不能因图中有名称就宣称已经实现。

## 6. 当前代码与第一个开发方向

**已有源码**：FVO Raw/原值/切片、MVI三刀状态、MPW四视图和OpenGL Raymarch、CT3D参数/LUT/ChangeSet；Windows Imaging历史回归通过，但不能替代真实GPU工业实测。

**重要缺口**：无损读取与缓冲所有权合同、完整3D空间Frame、MVI统一Camera/Scene、正式MPW GPU生命周期、Surface→拟合→测量的工业数值闭环、真实CAD/缺陷/动画验收。

**第一优先**：真实原值和坐标正确 → 保持现有四视图/GPU不退化 → 首个Surface/Fit/Measure数值闭环 → ResultRef/Scene显示与MEM保存 → 真实GPU和工业CT对照。不要一口气创造所有规划类。
