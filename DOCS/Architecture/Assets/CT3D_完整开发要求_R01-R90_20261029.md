# CxVisual 通用三维视觉工作台——完整开发要求

## 一、仓库与开发原则

01. 主仓库：`https://github.com/oudream/cx-visual-x3`。
02. 先阅读 `AGENTS.md`、开发 Skill、`DOCS/00～04` 架构基线。
03. 根据任务查阅 Architecture、Implementation、Testing 最新文档。
04. 核实最新 master、真实源码、项目依赖、测试及 Windows CI。
05. 全面审计 `ReferTo/Vision` 中已有的三维工具、控件和库。
06. 重点分析 `CxECT3DViewer`、`CxECTVolumeCore`、`CxECTVolumeWinForms`。
07. 同时复用 `CxECTImageWinForms`、HALCON 及已有二维能力。
08. **必须承接 x3 最近已迁移和重构的 FIM、FVO、MVI 等体系。**
09. 以现有代码为基础迁移、整合、重构、增构，不重新发明。
10. 核心原则：各方面都尽能力展现，便捷友好尽支撑各专业达到目标。

## 二、总体目标

11. 建设 **CxVisual 通用三维视觉工作台**。
12. 面向工业 CT、三维检测、无损检测、CAD 计量等应用。
13. 提供三维可视化、交互、动画、测量、分析、检测和算法调试。
14. 支持体数据、点云、网格、曲面、CAD 等多种三维对象。
15. 同时支持独立应用、嵌入式控件及开发者 API。
16. 功能完整、高性能、易操作、可扩展、可组合、可复用。
17. 基于 .NET Framework 4.8，正式界面以 WPF 为主。
18. 不把工作台开发成封闭、庞大的单体程序。

## 三、26 大完整功能能力

19. **多源三维数据输入**：RAW、DICOM、NRRD、TIFF序列、点云、网格、CAD。
20. 支持文件、内存、指针、共享内存、数据流及批量输入。
21. **体数据质量与空间标定**：体素间距、方向、坐标系、数据检查。
22. **三维数据处理与变换**：滤波、去噪、增强、重采样、插值、裁剪及变换。
23. **超大数据与高性能计算**：分块、缓存、LOD、按需读取、并行及 GPU。
24. **三维可视化与渲染**：体绘制、MIP/MinIP、等值面、点云、网格、透明度。
25. **多平面与高级重切片**：XY/XZ/YZ、任意斜切、曲面重切、厚层投影。
26. **多视图与空间交互**：四视图、分屏、三刀、十字线、同步定位。
27. **三维 ROI 与标注**：点、线、平面、球体、盒体、自由区域、图层及编辑。
28. **三维动画与时序可视化**：相机、模型、剖切、关键帧、时间轴和播放。
29. **三维分割与对象提取**：阈值、区域生长、连通域、多材料及 Mask。
30. **表面确定**：阈值、自适应、梯度、亚体素定位、多材料界面。
31. **点云与网格处理**：表面重建、三角化、平滑、简化、修补及法向。
32. **几何特征提取与拟合**：点、线、平面、圆、球、圆柱、圆锥、自由曲面。
33. **三维配准与坐标对齐**：基准对齐、特征匹配、最佳拟合、ICP。
34. **三维几何与尺寸测量**：距离、角度、面积、体积、直径、厚度及间隙。
35. **形位公差与 GD&T**：平面度、圆度、圆柱度、位置度、轮廓度等。
36. **CAD / SolidWorks 模型集成**：STEP、IGES、Parasolid、装配与特征。
37. **CAD 名义-实际比较**：CT↔CAD、点云↔CAD、网格↔CAD、偏差色谱。
38. **逆向工程与几何重建**：点云、网格、曲面、NURBS及参数化几何。
39. **三维缺陷与无损检测**：气孔、裂纹、夹杂、疏松、孔隙率及缺陷分布。
40. **壁厚、间隙与装配评价**：壁厚分布、最薄位置、干涉及配合分析。
41. **多材料、多部件与结构分析**：材料分离、界面、部件及结构统计。
42. **算法实验与调试**：算法、参数、输入输出、中间结果、性能及诊断。
43. **批处理与自动化检测**：检测方案、模板、批量任务、自动判定。
44. **数据输出与工程报告**：体数据、切片、网格、CAD、测量、分析、视频。
45. **SDK、插件与系统集成**：VTK、ITK、HALCON、OpenCV、CAD及专业算法。

## 四、重点能力必须做深做完整

46. 表面确定不能仅用简单等值面代替，需支持精度与质量评价。
47. 几何拟合支持最小二乘、鲁棒拟合、约束拟合及误差评价。
48. 配准支持人工、基准、自动及局部配准，并保存变换关系。
49. CAD 比较支持对齐、正负偏差、色谱、超差区域和统计报告。
50. SolidWorks 原生文件支持须验证依赖；优先实现可靠的标准格式接入。
51. 三维计量应支持测量基准、坐标系、公差、误差及结果追溯。
52. 支持体素、物理、世界、视图及 CAD 坐标的准确转换。
53. 原始高精度数据与降采样显示数据分离，禁止测量精度丢失。
54. 三维动画支持旋转、平移、缩放、相机漫游、剖切及透明渐变。
55. 支持装配、分解爆炸、缺陷定位、测量过程和分析过程动画。
56. 动画应支持时间轴、关键帧、编辑、保存、重放及视频输出。
57. 二维切片尽量直接复用通用二维视觉工作台的成熟能力。
58. 支持体数据、Mask、ROI、点云、网格、CAD、结果自由组合显示。
59. 各工具之间能够互相调用、组合、联动，不形成孤立功能。

## 五、未来高级能力

60. 预留 AI 智能三维能力，本阶段不开发具体 AI 功能。
61. 后续支持 AI 去噪、超分、伪影修复、智能分割及缺陷识别。
62. 后续支持智能测量、几何识别、模型推荐和辅助分析。
63. 预留真实 4D 动态数据、位移、形变及数字体相关分析。
64. 预留体网格、有限元数据交换、仿真及数字工程扩展。

## 六、架构与技术要求

65. `Foundation.Imaging`：统一二维图像、切片、像素和基础分析。
66. `Foundation.Volume`：体数据、体素、RAW、重采样、MPR 基础计算。
67. 复用现有 Geometry 及通用数学、几何和坐标变换能力。
68. `Mechanism.Visual`：三维会话、视口、三刀、ROI、对象与交互状态。
69. `Mechanism.Presentation.Wpf`：可复用二维、三维显示与操作控件。
70. `Professional.CT3D`：专业计量、分析、检测及相关算法。
71. 统一复用现有工程、数据、命令、编排、调度、日志和调试机制。
72. 不创建第二套工程树、Undo、数据管理、任务执行或渲染状态体系。
73. 第三方库明确依赖与职责，避免污染公共 Foundation。
74. 合理运用 OOP、GoF、AOP，不增加无必要的 Adapter、Wrapper、Facade。
75. 明确 CPU/GPU 内存所有权、线程安全、生命周期及资源释放。
76. 支持异步加载、取消、进度、缓存、局部更新和异常恢复。

## 七、实施与完整验收

77. 先建立旧代码、26项能力与 x3 已实现能力的完整映射。
78. 区分已实现、已验证、可复用、需重构、缺失及未来功能。
79. 先修复现有迁移问题和失败 CI，再按优先级持续增构。
80. 分阶段：体数据基础 → 三维显示交互 → 表面几何 → 计量 CAD → 高级分析。
81. 每阶段完成真实源码、可运行界面、开发者 API 和完整案例。
82. 用 TestCenter 验证真实鼠标交互、三刀联动、测量、分析和结果。
83. 验证 CT → 表面确定 → 几何拟合 → 尺寸及 GD&T 的完整链。
84. 验证 CT + CAD → 配准 → 偏差色谱 → 超差评价及报告的完整链。
85. 验证 CT → 分割 → 气孔/裂纹/壁厚分析 → 三维缺陷定位的完整链。
86. 验证四视图、三维动画、剖切、保存重放及视频输出。
87. 验证大数据、16位/浮点精度、性能、内存、显存及异常释放。
88. 必须有正反测试、Windows Debug/Release 构建与实际 CI 证据。
89. 遵守仓库提交规范，小步开发、中文 Commit、记录剩余差距。
90. **最终必须完整可用、可运行、可复用、可扩展；不能只交付文档、空类或演示界面。**
