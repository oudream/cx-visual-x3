# CxVisual 工程可视化——动态绑定、状态动画与实时预览闭环

**代码基准**：`master`（以提交 SHA 与匹配的 Windows CI 为准）  
**架构 Owner**：现有 `Foundation.Geometry`、`Mechanism.Core`、`Mechanism.Data`、`Mechanism.Visual`、`Mechanism.Presentation.Wpf`、`Applications.Studio`。  
**总目标**：真正可以由开发者 API 和工程用户 Studio 完成编辑、构建、运行观察、调试的工程可视化体系。本工作包属于运行可视化主线的纵向实现，并非整个体系已完成的证明。

## 1. 实际实现

| 位置 | 新能力 |
|---|---|
| `Mechanism.Visual/Runtime/MVIVisualRuntimeEvaluator.cs` | 通过已有 `IMDSExternalBindingResolver` （Mechanism.Data）解析 Variable/Expression 的强类型运行值。支持 Boolean/Number/String；类型不匹配拒绝而非静默转换 |
| `Mechanism.Visual/CxSceneProjection.cs` | 新增投影重载：`Project(session,pageId,source,elapsedMilliseconds)` 及资源投影同类接口；按实例和当前运行帧求值位置、显隐、状态样式、动画 |
| `Mechanism.Visual/CxVisualEditor.cs` | `SetRuntimeFrame(source,elapsedMilliseconds)` 与 `ClearRuntimeFrame()`；仅失效当前场景缓存，不写回 MEM、Undo 或工程 Revision |
| `Mechanism.Visual/Runtime/MVIVisualRuntimeEvaluator.cs` | 运行态 State 匹配样式；透明度动画支持线性、EaseIn、EaseOut、EaseInOut，重复与单次终止 |
| `Applications.Studio/StudioViewModel.cs` | `AttachVisualRuntimeSource(IMDSExternalBindingResolver)`：让现有专业数据 Owner 注入，Studio 不复制数据容器；`AddSelectedBreathingAnimation()` 持久化定义；帧更新不触发工程树全面刷新 |
| `Applications.Studio/MainWindow.xaml(.cs)` | 新增“添加呼吸动画”；切换“预览交互”后每约 50ms 对视觉帧采样，退出恢复设计态及工程样式；不直接执行设备命令 |
| `Mechanism.Presentation.Wpf/SceneView.cs`、`Widgets/MPWWidgetPresenter.cs` | 相同对象和控件类型的运行帧复用活动 WPF 控件，避免动画导致 TextBox 焦点/输入丢失，更新控件实际局部宽高、仿射位置和样式 |

**同一个工程定义、两种独立视图**：编辑态读取 `MPMAspect/MPMBinding` 的原始声明；运行预览使用来源 Owner 返回的值和采样时间得到 `CxSceneItem`。现场变量变化不得更新工程修改时间、Revision 或 Undo 栈。

## 2. 开发者API（仅使用现有机制）

```csharp
// source 由现有 MDS / 专业运行模块实现，不在 Visual 另建变量仓库。
IMDSExternalBindingResolver source = existingMdsOrProfessionalOwner;
using(var visual = new CxVisualEditor(project))
{
    visual.SetRuntimeFrame(source,500.0);
    var frame=visual.Scene;
    // frame 中显示的运行显隐、位置和样式来自 source，
    // project.Revision 不受这个只读显示帧影响。
    visual.ClearRuntimeFrame();
}
```

`MPMBinding.Variable("Motor.Ready")` 使用外部源的精确名字；若指定非默认成员，变量键为 `SourceId.MemberId`。失效/未加载数据返回 null 时回退工程值。错误类型抛出异常并应在宿主显示诊断，不允许悄悄变成默认值。Config、资源与成员绑定继续尊重已有专门 Owner，不借用 MDS Variable 假装统一完成。

Studio 的 `AttachVisualRuntimeSource(source)` 是真实联机接入点；仅点击预览按钮而**没有**提供 Owner 时，显示工程默认值，但无触发条件的动画仍能按时钟实际运行。

## 3. 风格优先级和安全

- 显式 `IsVisible=false` 是硬约束：即使动态绑定返回 true，也不能把隐藏对象暴露到运行画布。
- 工程 Style 是基础，活跃 State 依序覆盖 Style，当前时刻动画覆盖受支持的 `opacity` 数值；多状态同时匹配时最后一项优先，未来须增加显式优先级规格。
- 帧时间由宿主提供：无隐式全局定时器或后台线程。WPF Studio 使用受 UI 线程调度的 `DispatcherTimer`，`StopVisualRuntime` 归零。
- 不创建第二个 `DataManager`、`VariableRepository`、`RuntimeHeap`、工程编辑历史或持久动画值容器。
- UI Widget 事件仍须交由现有 MRK/专业命令与权限/安全联锁判断；此处只负责可视呈现，不触发设备动作。
