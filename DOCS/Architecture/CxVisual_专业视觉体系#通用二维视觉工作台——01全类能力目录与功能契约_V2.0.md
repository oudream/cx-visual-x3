# CxVisual 通用二维视觉工作台——01 全类能力目录与功能契约 V2.0

> **定位**：26个一级类及260个可追踪二级能力的唯一目标清单。编号V2D-XX.YY保持稳定；后续新增三级能力用V2D-XX.YY.ZZ，不因UI菜单排序改ID。日期2026-10-28。**这里是目标，不等于已编码**；已实现范围见历史V1.0/V1.1及Implementation/Testing实证，禁止按清单宣称成熟。
>
> **设计规则**：一个能力必须包括业务语义、类型化输入、输出、参数/单位/坐标、错误/取消、用户入口和API、Owner、UML、测试；公共机制归平台，专业算法归Vision；复用既有MEM/MRC/MRK/MDS。全类ID只在本文维护，专题不再复制另立类编号。

## 1. 总体分类、横向契约与验收等级

六群：A数据01—04、B呈现05—09、C算法10—17、D执行18—20、E工程21—23、F产品24—26。每个类标出**首选Owner**，具体新类型与接口须按当前csproj与DOCS/02—04复核，不能由本文件自动批准。
`E`=实际源码可查，`R`=在已有Owner上待完善，`N`=必须审查后新增，`P`=仅设计/待验证。状态必须按最细功能而非整类统计；编译/自动/人工/现场各有独立证据，不互相代替。

| 公共输入语义 | 输出语义 | 契约约束 |
|---|---|---|
| Image/Frame/DataHandle | Image/Mask/ArtifactRef | 位深、Stride、坐标、来源、所有权、版本 |
| ROI/Geometry/Calibration | Region/Measurement | 原图坐标与物理单位，退化几何拒绝 |
| Parameters/Capability/ModelRef | Typed VisionResult | 参数Schema、Provider、版本和质量 |
| ResourceRef/ExecutionPlan/Invocation | RunId/Trace/ResultRef | 读稳定定义、超时取消、权限及资源预算 |
| ImageStream/Sequence | FrameResults/Event/State | 时间戳、背压、丢帧政策、顺序与观测 |

## 5. 版本演进规则

新增功能必须先判断是否属于已有二级能力，再新增三级ID；确有独立语义才新增二级；新增一级必须经过Owner与能力分类ADR。旧ID永不重用；废弃标记Deprecated并提供替代映射。修改类定义时同步更新02 UML、对应专题、Implementation及Testing；现有60项需求及ReferTo迁移表必须持续向这些ID追溯，不替代历史原始需求。
