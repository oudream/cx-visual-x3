## 明确局限

1. WPF 的 PerMonitorV2 manifest 是请求而不是测试结果；不能以读取 DPIScale 代替跨显示器人工验证。
2. 本 PoC 不接 MEM、MDS、MRK 或 PLC。Rev 是独立的工程状态**替身**，不是对真实 x3 工程仓库的运行验证。
3. 不能因为 `XmlLayoutSerializer` 序列化了布局就断言窗口位置/浮窗多屏行为完全恢复；必须人工测试。
4. 自动测试未证明拖动、自动隐藏动画流畅、焦点/键盘导航、主题视觉以及 Release 长稳；均以人工和性能记录收口。
