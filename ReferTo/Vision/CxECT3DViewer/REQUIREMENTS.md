# CxECT3DViewer 需求分析

## 背景

本工具基于 OpenTK 3.3.3 和 .NET Framework 4.8，用于工业 CT / ECT 体数据的 3D 看图与切片查看。

参考图展示的是典型四视图体数据工作站界面：三个正交 2D 切片视图加一个 3D 体渲染视图。目标不是只做一个可旋转的 3D 预览窗口，而是做一个可用于检查、定位和联动观察的 3D 看图工具。

## 参考图观察

参考图中的界面大致由四个视图组成：

- 左上：一个正交 2D 切片视图，类似 Front / Coronal。
- 右上：一个正交 2D 切片视图，类似 Side / Sagittal。
- 左下：一个正交 2D 切片视图，类似 Top / Axial。
- 右下：3D 体渲染视图，显示半透明模型，并叠加三张彩色切面平面。

图中还可以观察到：

- 三个 2D 视图都有十字线，用于表示当前 X / Y / Z 切片位置。
- 3D 视图中有红、绿、蓝三张半透明切面平面。
- 2D 视图和 3D 视图的切面位置是联动的。
- 每个视图附近有色标或灰度标尺，用于表达体素值、伪彩色或显示映射。
- 顶部存在工具栏，可能包含打开文件、平移、缩放、测量、选择、复位视角、切面显示等操作。

## 核心目标

加载一份 3D RAW 体数据后，工具应同时提供三个正交 2D 切片视图和一个 3D 体渲染视图。用户在任意视图中调整切片位置时，四个视图应实时同步。

一句话目标：

> 做一个工业体数据四视图 MPR + 3D 体渲染联动查看器。

## 功能需求

### 1. 四视图布局

主界面需要提供 2x2 四视图区域：

- `XY` 横截面视图。
- `XZ` 纵向切片视图。
- `YZ` 纵向切片视图。
- 3D 体渲染视图。

每个视图应有清晰的标题或方向标识，避免用户无法判断当前观察的是哪个平面。
每个视图可以放到最大来占满四视图整个区域。
3D显示是降采样的体积数据，那能不能同时保存一个原始的数据用来做切面用。
3D视图中需显示三个方向的彩色切面平面，平面范围按对应2D视图当前可视窗口生成，而不是固定限制在体积内部。三个切面分别对应XY、XZ、YZ视图，并在3D空间中按当前sliceX、sliceY、sliceZ位置摆放；2D视图缩放、平移或滚动切片时，3D中对应平面同步改变大小、位置或所在切片。

### 2. 2D 正交切片显示（使用HWindowControlView、HalconWindowTools来封装）

三个 2D 视图需要从当前体数据中提取对应平面的灰度图：

- `XY` 视图显示固定 `Z` 的切片。
- `XZ` 视图显示固定 `Y` 的切片。
- `YZ` 视图显示固定 `X` 的切片。

2D 切片应支持：

- 灰度显示。
- 伪彩色显示。
- 按窗口缩放适配。
- 鼠标滚轮切换当前平面的切片索引。
- 平移和缩放。
- 显示当前鼠标位置的体素坐标和值。

### 3. 十字线联动

三个 2D 视图都需要显示十字线。十字线代表全局当前点：

- 当前 `X` 切片索引。
- 当前 `Y` 切片索引。
- 当前 `Z` 切片索引。

用户在任意 2D 视图中拖动十字线时，应更新共享的全局切片状态，并触发其它两个 2D 视图和 3D 视图刷新。

示例：

- 在 `XY` 视图中拖动十字线横向位置，应更新 `SliceX`。
- 在 `XY` 视图中拖动十字线纵向位置，应更新 `SliceY`。
- 滚轮切换 `XY` 视图深度时，应更新 `SliceZ`。

### 4. 3D 体渲染视图

3D 视图需要显示：

- 半透明体渲染结果。
- 体数据外框。
- 当前 X / Y / Z 三张彩色切面平面。
- 方向指示器。

3D 视图应支持：

- 左键旋转。
- 滚轮缩放。
- 复位视角。
- 切面显示开关。
- 体渲染透明度调节。
- 切面透明度调节。

### 5. 3D 切面与 2D 视图关联

3D 视图中的三张彩色切面平面必须与其它三个 2D 视图共享同一套切片状态。

关联规则：

- 3D 中的 `X` 切面位置由 `SliceX` 决定，对应 `YZ` 视图当前显示的切片。
- 3D 中的 `Y` 切面位置由 `SliceY` 决定，对应 `XZ` 视图当前显示的切片。
- 3D 中的 `Z` 切面位置由 `SliceZ` 决定，对应 `XY` 视图当前显示的切片。
- 当用户在 2D 视图中拖动十字线或滚轮切片时，3D 视图中的彩色切面平面必须同步移动。
- 当后续支持在 3D 视图中拖动彩色切面时，三个 2D 视图也必须同步刷新。

大小和位置要求：

- 三张彩色切面平面的大小必须严格匹配体数据的物理外框。
- 切面平面不能只按降采样后的纹理尺寸显示，应按原始体数据尺寸和体素间距计算真实比例。
- 如果体素间距不是 `1x1x1`，3D 切面尺寸需要体现真实物理比例。
- 2D 视图中的切片位置和 3D 视图中的切面位置应由同一个 `VolumeState` 或等价状态对象驱动，避免出现视觉不同步。

### 6. 色标与显示映射

工具需要显示当前灰度 / 伪彩色映射关系：

- 2D 视图旁可显示灰度或伪彩色标尺。
- 3D 视图可显示 transfer function 对应的色标。
- 色标范围应与当前体数据的归一化范围或原始值范围对应。

后续如果需要工程测量或缺陷分析，应优先保留原始体素值范围，而不是只保留归一化后的 8-bit 数据。

### 7. 工具栏

第一阶段工具栏建议包含：

- 打开 RAW 文件。
- 重置四视图。
- 适应窗口。
- 显示 / 隐藏十字线。
- 显示 / 隐藏 3D 切面。
- 显示 / 隐藏体渲染。
- 截图。
- 灰度窗宽窗位或阈值调节。

后续可扩展：

- 距离测量。
- 角度测量。
- 缺陷标注。
- 标注导出。
- 截面保存。

## 数据与性能需求

当前项目已经会把大 RAW 数据降采样到最大 512 轴用于 3D 交互。这适合 3D 预览，但 2D 看图通常需要更高精度。

建议数据策略：

- 3D 体渲染使用降采样数据，保证旋转和缩放流畅。
- 2D 切片优先使用原始分辨率，或按当前视图缩放比例按需读取。
- `VolumeData` 保留显示尺寸、原始尺寸、体素间距和灰度范围。
- 后续如需要测量，应明确区分体素坐标和物理坐标。

## 当前项目已有能力

当前代码已经具备：

- RAW 文件加载。
- 从文件名推断体数据尺寸。
- 支持 Byte / UInt16 / Float32 RAW。
- 大体数据降采样。
- 3D 纹理上传。
- OpenGL raymarch 体渲染。
- 三张 3D 切面。
- 体数据外框。
- 方向指示器。
- Transfer Function 编辑。
- `SliceX` / `SliceY` / `SliceZ` 状态对象。

## 当前项目主要缺口

与参考图目标相比，目前主要缺少：

- 三个独立的 2D 正交切片视图。
- 2D 十字线绘制。
- 2D 视图拖动十字线更新切片状态。
- 2D 鼠标滚轮切片。
- 2D 坐标和值显示。
- 四视图 2x2 布局。
- 3D 彩色切面与 2D 视图的明确颜色和方向约定。
- 原始分辨率 2D 切片读取策略。

## 建议第一阶段 MVP

第一阶段建议先实现最小可用四视图：

1. 新增 `SliceViewControl`，用于显示单个 2D 切片。
2. 主界面改为 2x2 四视图布局。
3. 三个 `SliceViewControl` 分别绑定 `XY`、`XZ`、`YZ`。
4. 三个 2D 视图共用当前 `VolumeState`。
5. 支持 2D 十字线显示和拖动。
6. 支持鼠标滚轮切换当前平面的切片索引。
7. 3D 视图继续复用现有 `VolumeRenderControl`。
8. 统一 3D 彩色切面和 2D 十字线的颜色约定。

建议颜色约定：

- `X` 切面：红色。
- `Y` 切面：绿色。
- `Z` 切面：蓝色。

## 验收标准

第一阶段完成后应满足：

- 启动后可以看到 2x2 四视图界面。
- 加载 RAW 后，三个 2D 视图显示对应正交切片。
- 三个 2D 视图都有十字线。
- 拖动任意 2D 视图十字线，其它视图同步更新。
- 滚动任意 2D 视图鼠标滚轮，对应切片索引变化。
- 3D 视图中的三张彩色切面位置与三个 2D 视图完全一致。
- 3D 彩色切面大小与体数据物理外框一致。
- 非等距体素数据在 3D 视图中仍按真实物理比例显示。
- 构建通过：`dotnet msbuild .\CxECT3DViewer.csproj -p:GenerateResourceMSBuildArchitecture=CurrentArchitecture`。

## 当前实现状态

截至当前版本，第一阶段四视图 MVP 已在本项目内落地：

- `FourViewLayoutControl` 提供 2x2 四视图布局，并支持单视图最大化占满四视图区。
- `HalconSliceViewControl` 基于 `HWindowControlView`、`HalconWindowTools`、`HWindowControl` 提供 `XY`、`XZ`、`YZ` 三个 2D 正交切片视图。
- 三个 2D 视图支持十字线、左键拖动联动、鼠标滚轮切片、右键/中键平移、`Ctrl + 滚轮` 缩放、双击适应窗口。
- 2D 视图支持灰度显示、伪彩色显示、灰度/伪彩色色标、窗宽窗位调节、体素坐标和值显示、物理坐标显示。
- 加载 RAW 后，2D 切片优先按原始 RAW 文件按需读取；3D 体渲染继续使用降采样数据保证交互流畅。
- `VolumeState` 使用原始体素坐标统一驱动 `SliceX`、`SliceY`、`SliceZ`，保证 2D 十字线、右侧滑条和 3D 切面位置一致。
- 3D 视图支持体渲染、体数据外框、方向指示器、X/Y/Z 三张彩色切面、体渲染开关、切面开关、体渲染强度、切面透明度、transfer function 色标。
- 3D 切面使用原始体数据尺寸和体素间距计算真实物理比例，不按降采样纹理尺寸决定外形。
- 主界面提供加载 RAW、保存四视图截图、重置/适应四视图、显示/隐藏十字线、显示/隐藏切面、显示/隐藏体渲染、2D 伪彩色、2D 窗宽窗位、transfer function 调节。

HALCON 说明：

- 当前 2D 显示层已接入 `Drivers/HalconDriverModule/bin/Debug` 中的 `HalconDriverModule.dll`、`halcondotnetxl.dll` 和相关运行时依赖。
- HALCON XL 运行时为 64 位，项目 Debug/Release 均固定 `PlatformTarget=x64`，避免 32 位进程加载 HALCON 时出现 `BadImageFormatException`。
- `SliceViewControl` 仍保留在项目中作为轻量 GDI+ fallback 参考；当前四视图实际使用 `HalconSliceViewControl`。

## 最新联动修正

3D 视图中的红、绿、蓝三张切面平面表示对应 2D 视图的当前可视窗口，而不是固定限制在体积内部的完整切片。用户在 XY、XZ、YZ 任一 2D 视图中缩放时，3D 中对应平面的大小同步变化；当 2D 视图缩小到可见范围大于体积时，3D 平面允许超过体积外框。用户平移 2D 视图时，对应 3D 平面也应按相同观察窗口范围同步平移；滚动切片时，对应平面沿 SliceX、SliceY 或 SliceZ 所在轴移动。
